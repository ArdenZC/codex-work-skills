# 平时成绩记分册生成器

## 简介

平时成绩记分册生成器用于从湖北职业技术学院格式的 `课程成绩单.xls` 自动生成 `平时成绩记分册.xls`。它内置平时成绩记分册模板，会读取课程名称、教师、班级、开课学期、成绩比例、学号、姓名、理论成绩、平时成绩、技能成绩和总成绩，并按 manifest 定义生成平时成绩项目（当前模板为 8 次）。

生成的平时成绩项目数量由 manifest 定义（当前模板为 8 次），使用确定性随机算法，围绕原始平时成绩小幅波动，平均值严格等于课程成绩单中的平时成绩。学生行数会按课程成绩单人数保留，多余模板行会删除；当 `技能成绩` 比例为 `0%` 时，会自动删除技能成绩及技能折合两列。

## 适用场景

- 已有 `课程成绩单.xls`，需要批量或单班生成平时成绩记分册。
- 需要把单一平时成绩总分拆成 manifest 定义的多次平时成绩。
- 不同班级成绩比例不同，需要自动保留或删除技能成绩列。
- 需要保留学校平时成绩记分册模板样式和 `.xls` 文件格式。

## 必须提供的资料

- `课程成绩单.xls` 文件，或包含该文件的班级文件夹。

调用这个 skill 时，如果没有提供课程成绩单，Codex 应提醒用户上传或提供 `课程成绩单.xls`。

模板已内置在 skill 包中，不需要另外提供记分册模板：规范模板位于 `assets/templates/course-gradebook/v1.0.0/template.xls`，旧的 `assets/平时成绩记分册模板.xls` 仍作为兼容入口。`manifest.yaml` 是 Python 与 Excel COM 两条路径共用的坐标和保护规则来源；输入契约见 `schemas/gradebook-input.schema.json`。

## 平台支持

- Windows：优先使用 `scripts/generate_gradebook.ps1`，依赖 Microsoft Excel COM，保留 `.xls` 模板格式最稳定。
- macOS / Linux：使用 `scripts/generate_gradebook.py`，依赖 Python 3、`openpyxl` 和 LibreOffice/soffice。脚本会通过 LibreOffice 转换 `.xls`，再写入并转回 `.xls`。

macOS 上需要先安装 LibreOffice，并确保 `soffice` 可用；如果没有安装，skill 会提示先安装 LibreOffice。

生成流程为：输入资料 → 标准化数据 → schema 校验 → 模板校验 → 生成 → 输出校验 → `qa-report.json`。QA 报告会记录模板/生成器版本、实际模板路径、自定义模板标记、生成引擎和校验跳过项，不记录学生姓名、学号或成绩原始数据。默认启用校验，只有显式传入跳过参数才会关闭对应检查；跳过时仍写报告并标记为 `skipped`。

Windows Excel COM 负责保留 `.xls` 原生格式；默认 QA 仍通过 Python/LibreOffice 转换检查输出。如果 Windows 机器只有 Excel 而没有 LibreOffice，可以显式跳过模板或输出校验，但必须接受 QA 报告中的 `skipped` 状态。

## 安装

将 `course-gradebook-generator` 文件夹复制到本机 Codex skills 目录：

```powershell
Copy-Item -Recurse ".\平时成绩记分册生成器\course-gradebook-generator" "$env:USERPROFILE\.codex\skills\course-gradebook-generator"
```

也可以运行内置安装脚本：

```powershell
python ".\平时成绩记分册生成器\course-gradebook-generator\scripts\install.py" --replace
```

macOS 或 Linux 可运行：

```bash
python3 "./平时成绩记分册生成器/course-gradebook-generator/scripts/install.py" --replace
```

## 调用方式

在 Codex 中可以直接说：

```text
使用平时成绩记分册生成器，根据这个课程成绩单生成平时成绩记分册。
```

或显式调用：

```text
使用 $course-gradebook-generator 处理这个班级文件夹里的课程成绩单。
```

## 多Agent兼容

本技能不绑定某一个模型或 AI 工具。AI 负责定位和理解 课程成绩单.xls，内置 Windows PowerShell 或 macOS/Linux Python 生成器负责保留模板格式、拆分 8 次成绩并校验结果。包内提供 AGENTS.md、CLAUDE.md、GEMINI.md、通用提示词.md、Aider 约定，以及可安装到 Cursor、Cline、Continue、Windsurf 和 GitHub Copilot 的规则适配器。

其他工具请先读取通用提示词.md；需要把规则复制到另一个项目时，运行：
python course-gradebook-generator/scripts/install_adapters.py --target-dir /path/to/project
