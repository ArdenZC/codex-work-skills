# 平时成绩记分册生成器

## 简介

平时成绩记分册生成器用于从湖北职业技术学院格式的 `课程成绩单.xls` 自动生成 `平时成绩记分册.xls`。它内置平时成绩记分册模板，会读取课程名称、教师、班级、开课学期、成绩比例、学号、姓名、理论成绩、平时成绩、技能成绩和总成绩，并按 manifest 定义生成平时成绩项目（当前模板为 8 次）。

生成的平时成绩项目数量由 manifest 定义（当前模板为 8 次），使用确定性随机算法，围绕原始平时成绩小幅波动，平均值严格等于课程成绩单中的平时成绩。v1.0 使用 legacy coordinates，学生行数按课程成绩单人数保留，多余模板行会删除；v1.1 使用 workbook-level `gb_` named ranges，48 人以内保留至第 52 行，超过容量时精确扩展至最后一名学生，`gb_template_row` 始终为第 5 行样式来源。当 `技能成绩` 比例为 `0%` 时，会自动删除技能成绩及技能折合两列。

## 适用场景

- 已有 `课程成绩单.xls`，需要批量或单班生成平时成绩记分册。
- 需要把单一平时成绩总分拆成 manifest 定义的多次平时成绩。
- 不同班级成绩比例不同，需要自动保留或删除技能成绩列。
- 需要保留学校平时成绩记分册模板样式和 `.xls` 文件格式。

## 必须提供的资料

- `课程成绩单.xls` 文件，或包含该文件的班级文件夹。

调用这个 skill 时，如果没有提供课程成绩单，Codex 应提醒用户上传或提供 `课程成绩单.xls`。

模板已内置在 skill 包中，不需要另外提供记分册模板：默认规范模板位于 `assets/templates/course-gradebook/v1.1.0/template.xls`，v1.0 坐标模板位于 `assets/templates/course-gradebook/v1.0.0/template.xls`，旧的 `assets/平时成绩记分册模板.xls` 仍作为 v1.0 兼容入口。v1.1 使用 24 个 `gb_` 前缀的 workbook-level named ranges；无技能成绩时保留 21 个名称并删除技能成绩相关两列。`manifest.yaml`、命名区域契约和原始 BIFF/XLSX 校验是 Python 与 Excel COM 两条路径共用的来源；输入契约见 `schemas/gradebook-input.schema.json`。

## 平台支持

- Windows 和 macOS 是当前正式持续验证平台。
- Windows：优先使用 `scripts/generate_gradebook.ps1`，依赖 Microsoft Excel COM，保留 `.xls` 模板格式最稳定。
- macOS：使用 `scripts/generate_gradebook.py`，依赖 Python 3、`openpyxl` 和 LibreOffice/soffice。脚本会通过 LibreOffice 转换 `.xls`，再写入并转回 `.xls`。
- Linux：LibreOffice Python 路径在设计上保持兼容，但当前不属于持续集成验收平台。

macOS 上需要先安装 LibreOffice，并确保 `soffice` 可用；如果没有安装，skill 会提示先安装 LibreOffice。

生成流程为：输入资料 → 标准化数据 → schema 校验 → 模板校验 → 临时候选生成 → raw runtime 检查 → 完整或 skip QA → XLS 与 `qa-report.json` 原子替换。失败时既有正式输出和输出目录中的无关 XLS 保持不变，只清理本次临时文件。v1.1 默认通过命名区域写入，不能静默降级为坐标模式；学生人数超过 48 时，所有动态数据命名区域扩展到实际末行。QA 报告会记录模板/生成器版本、anchor mode、命名区域变体、实际模板路径、自定义模板标记、生成引擎和校验跳过项，不记录学生姓名、学号或成绩原始数据。默认启用校验，只有显式传入跳过参数才会关闭对应完整检查；skip QA 仍检查真实非空 `.xls`，v1.1 仍检查原始 named-range inventory，并标记为 `skipped`。

Windows Excel COM 负责生成并保留 `.xls` 原生格式，Python 的 `xlrd`/`olefile` 负责不可跳过的 raw XLS preflight，并使用同一组 workbook-level named ranges；LibreOffice 只用于完整 round-trip、格式和渲染 QA。Windows 机器只有 Excel 而没有 LibreOffice 时，同时显式跳过模板和输出 QA 仍可完成生成，但必须接受 QA 报告中的 `skipped` 状态；fingerprint、raw runtime 和输出基础真实性检查仍不可跳过。

## 安装

### 推荐：让 AI 安装

请安装当前仓库中的平时成绩记分册生成器 Skill。阅读本目录的简介、`SKILL.md` 和依赖说明后，将 `course-gradebook-generator` 安装到当前 AI 工具对应的 Skill 目录，并验证安装结果。

### Codex 手动安装

Windows：

```powershell
python ".\平时成绩记分册生成器\course-gradebook-generator\scripts\install.py"
```

macOS：

```bash
python3 "./平时成绩记分册生成器/course-gradebook-generator/scripts/install.py"
```

默认安装到 `~/.codex/skills/course-gradebook-generator/`。如果目标目录已经存在，使用 `--replace` 才会替换；该选项会先备份已有安装再替换。也可以使用 `--skills-dir` 指定 Codex skills 目录。

## 调用方式

在 Codex 中可以直接说：

```text
使用平时成绩记分册生成器，根据这个课程成绩单生成平时成绩记分册。
```

或显式调用：

```text
使用 $course-gradebook-generator 处理这个班级文件夹里的课程成绩单。
```

## 多Agent兼容

本技能不绑定某一个模型或 AI 工具。AI 负责定位和理解课程成绩单.xls，内置 Windows PowerShell 或 macOS/Linux Python 生成器负责按 v1.1 命名区域契约保留模板格式、拆分 8 次成绩并校验结果。包内提供 AGENTS.md、CLAUDE.md、GEMINI.md、通用提示词.md、Aider 约定，以及可安装到 Cursor、Cline、Continue、Windsurf 和 GitHub Copilot 的规则适配器。

其他工具请先读取通用提示词.md；需要把规则复制到另一个项目时，运行：
python course-gradebook-generator/scripts/install_adapters.py --target-dir /path/to/project
