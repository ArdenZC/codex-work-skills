# 平时成绩记分册生成器

## 简介

平时成绩记分册生成器用于从湖北职业技术学院格式的 `课程成绩单.xls` 自动生成 `平时成绩记分册.xls`。它内置平时成绩记分册模板，会读取课程名称、教师、班级、开课学期、成绩比例、学号、姓名、理论成绩、平时成绩、技能成绩和总成绩，并按 manifest 定义生成平时成绩项目，当前模板为 8 次。

生成的平时成绩项目数量由 manifest 定义，使用确定性随机算法围绕原始平时成绩小幅波动，平均值严格等于课程成绩单中的平时成绩。v1.0 使用 legacy coordinates，学生行数按课程成绩单人数保留，多余模板行会删除；v1.1 使用 workbook-level `gb_` named ranges，48 人以内保留至第 52 行，超过容量时精确扩展至最后一名学生，`gb_template_row` 始终为第 5 行样式来源。当 `技能成绩` 比例为 `0%` 时，会自动删除技能成绩及技能折合两列。

## 适用场景

- 已有 `课程成绩单.xls`，需要批量或单班生成平时成绩记分册；
- 需要把单一平时成绩总分拆成 manifest 定义的多次平时成绩；
- 不同班级成绩比例不同，需要自动保留或删除技能成绩列；
- 需要保留学校平时成绩记分册模板样式和 `.xls` 文件格式。

## 必须提供的资料

- `课程成绩单.xls` 文件，或包含该文件的班级文件夹。

调用这个 Skill 时，如果没有提供课程成绩单，Agent 应提醒用户上传或提供 `课程成绩单.xls`，不会凭空生成成绩。

## 模板与质量规则

模板已内置在 Skill 包中，不需要另外提供记分册模板。默认规范模板为 `assets/templates/course-gradebook/v1.1.0/template.xls`，v1.0 坐标模板为 `assets/templates/course-gradebook/v1.0.0/template.xls`，旧的 `assets/平时成绩记分册模板.xls` 仍作为 v1.0 兼容入口。

v1.1 使用 24 个 `gb_` 前缀的 workbook-level named ranges；无技能成绩时保留 21 个名称并删除技能成绩相关两列。`manifest.yaml`、命名区域契约和原始 BIFF/XLSX 校验是 Python 与 Excel COM 两条路径共用的来源。输出 QA 会检查学生行数、学号姓名顺序、平时成绩平均值、总评公式、技能成绩列和 named-range inventory。

生成流程为：输入资料 → 标准化数据 → schema 校验 → 模板校验 → 临时候选生成 → raw runtime 检查 → 完整或 skip QA → XLS 与 `qa-report.json` 原子替换。失败时既有正式输出和输出目录中的无关 XLS 保持不变，只清理本次临时文件。v1.1 不能静默降级为坐标模式；显式 skip QA 时仍检查真实非空 `.xls` 和原始 named-range inventory，并将报告标记为 `skipped`。

## 平台支持

- Windows 和 macOS 是当前 CI 与交付验收平台；
- Windows：Excel COM 是推荐生成路径，依赖 Microsoft Excel；Python 的 `xlrd`/`olefile` raw XLS preflight 始终执行；完整 LibreOffice round-trip、格式和渲染 QA 可选；
- macOS：使用 Python + LibreOffice/`soffice` 完成 `.xls` 转换、写入和回转；
- Linux：Python + LibreOffice 路径设计上保持兼容，但当前不属于持续集成验收平台。

macOS 运行前请安装 LibreOffice 并确保 `soffice` 可用。如果 Windows 同时显式跳过模板和输出 QA，机器上只有 Excel 而没有 LibreOffice 也可以完成生成，但 QA 报告会标记为 `skipped`；fingerprint、raw runtime 和输出基础真实性检查仍不可跳过。

## 安装

### 推荐：让 AI Agent 安装

将下面的提示词交给具备本地文件访问、Git 和终端执行能力的 Agent：

```text
请安装当前仓库中的平时成绩记分册生成器 Skill。

请先阅读：
- 仓库 README
- 仓库根目录的 AGENTS.md
- 平时成绩记分册生成器/简介.md
- 平时成绩记分册生成器/course-gradebook-generator/AGENTS.md
- 平时成绩记分册生成器/course-gradebook-generator/通用提示词.md
- 平时成绩记分册生成器/course-gradebook-generator/SKILL.md

检查本机 Python、Excel 或 LibreOffice 依赖后，将 course-gradebook-generator 安装到当前 AI 工具对应的 Skill 目录，并验证安装结果。

如果当前工具是 Codex，优先使用 scripts/install.py。
不要修改源码、模板或 manifest。
```

纯网页聊天工具如果没有本机文件和命令权限，不能直接完成安装。

### Codex 手动安装

Windows PowerShell：

```powershell
python ".\平时成绩记分册生成器\course-gradebook-generator\scripts\install.py"
```

macOS Terminal：

```bash
python3 "./平时成绩记分册生成器/course-gradebook-generator/scripts/install.py"
```

默认安装到 `~/.codex/skills/course-gradebook-generator/`。目标目录已存在时，默认不会覆盖；使用 `--replace` 才会先备份再替换，也可以使用 `--skills-dir <目录>` 指定 Codex skills 目录。`--dry-run` 只显示计划路径。安装脚本负责复制 Skill 文件；Python 依赖按 `requirements.txt` 安装，Excel COM 或 LibreOffice 依赖按平台准备。

## 调用方式

在已安装的 Agent 中可以直接说：

```text
使用平时成绩记分册生成器，根据这个课程成绩单生成平时成绩记分册。
```

或显式调用：

```text
使用 $course-gradebook-generator 处理这个班级文件夹里的课程成绩单。
```

## 多 Agent 兼容

本 Skill 不绑定某一个模型或 AI 工具。AI 负责定位和理解 `课程成绩单.xls`，内置 Windows PowerShell 或 macOS Python 生成器负责按 v1.1 命名区域契约保留模板格式、拆分 8 次成绩并校验结果。包内提供 `AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`通用提示词.md`、Aider 约定，以及可安装到 Cursor、Cline、Continue、Windsurf 和 GitHub Copilot 的规则适配器。

需要把规则复制到另一个项目时，运行：

```powershell
python "course-gradebook-generator/scripts/install_adapters.py" --target-dir "<project>"
```

macOS 使用 `python3`。默认不覆盖目标项目中的已有规则，明确传入 `--replace` 才会备份并替换。
