# 整门课程编排器

本目录实现 Whole-Course Orchestration 1.0 的第一阶段架构。它输出课程级 JSON 合同与干净课程包，供稳定的 Courseware / Practice HTML Skill 消费。

## 不做什么

- 不渲染 HTML、CSS 或 JavaScript；
- 不以课程名、文件名或 UML 特例选择模板；
- 不把旧 16+16 失败合同读取为新生成输入；
- 不在架构评审前运行真实 9 份 PPT 的 whole-course retry。

详细工作流见 [SKILL.md](SKILL.md) 和仓库根目录 [WHOLE-COURSE-ARCHITECTURE-REPORT.md](../../WHOLE-COURSE-ARCHITECTURE-REPORT.md)。
