# 实践任务工单生成器 2.2.0

本 Skill 负责把 Agent 创作的实践任务 WorkOrder Content 1.1 写入真实 Word 模板 `practice-work-order v1.0.0`。当前为 Phase 2.2 收口，不宣称 Phase 3 的整门课程扩展。

关联模式使用 Lesson 的 Practice Task Contract 1.1 作为唯一上游事实源。每个 Practice Task 固定 2 学时、一项任务对应一份 WorkOrder；关联 Content 必须携带完整来源任务快照、课程基本盘和 Agent pedagogical review。发现冲突时失败并要求重写下游 Content，不修改 Lesson。

独立模式必须明确选择，仅用于没有上游 handoff 的独立创作或调试，不能声称已完成跨文档联动。只有关联模式默认真实渲染并在 `render.status=pass` 后报告生产成功；standalone/debug 显式跳过渲染时只能报告未进入生产门禁。

每份工单固定考勤 10 分、任务项合计 90 分、总分 100 分。学生“任务结果”栏保持空白，学生可见区域默认隐藏任务、项目和课次内部 ID，不生成教师答案或最终业务结论。

`--practice-task-json` 只做上游合同校验和 Agent 创作骨架输出；不能单独生成正式 Content 或 DOCX。旧 V1 只可通过显式 `--legacy` 迁移。安装器不自动安装 Python 依赖；模板 binary 和版本保持不变。正式安装后可运行 `scripts/install.py --doctor --json --skills-dir <目录>`，确认 source/installed fingerprint 相等且 `status=current`。
