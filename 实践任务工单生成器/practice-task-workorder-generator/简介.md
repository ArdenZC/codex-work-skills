# 实践任务工单生成器

这是一个独立的、实验性的 Phase 1 Skill，用于把结构化实践任务内容写入用户提供的真实 Word 学习工单模板。

它消费两种输入：

1. `Practice Work Order Content V1`，作为直接生成输入；
2. Lesson Skill 产出的 `Practice Task Contract V1`，作为最小 handoff 输入，由本 Skill 做结构映射，不复制 Lesson 的课程规划合同。

Phase 1 固定以下产品边界：

- 每份工单固定 100 分：出勤 10 分，任务项合计 90 分；
- 学生结果区保持空白，不生成答案、SQL、最终图或教师答案；
- 学生评价表和教师评价表沿用 canonical 模板的固定结构；
- 任务项必须给出工具/材料、步骤、交付物和验收标准；
- 允许每课一个或多个任务，但不在 Phase 1 处理 Lesson DOCX 的跨工件一致性；
- 不包含 Phase 2 的全链路 Cross Artifact QA、CI、发布、教师答案和成绩册联动。

默认模板为 `practice-work-order v1.0.0`。该模板来自真实用户文档的只读审计副本，安装和生成过程不会覆盖 canonical binary。
