# 实践任务工单生成器

这是一个 Phase 2 / 联动候选 Skill，用于把 Lesson Skill 的 Practice Task Contract V1 转换为可执行的学生实践学习工单，并写入真实用户模板 `practice-work-order v1.0.0`。它尚未宣称 Phase 3 的完整 64 学时稳定版。

它消费两种输入：

1. `Practice Work Order Content V1`，作为直接生成输入；
2. Lesson Skill 产出的 `Practice Task Contract V1`，作为唯一上游 handoff。

Practice Task Contract 的 canonical schema 在仓库 `schemas/shared/practice-task-contract.schema.json`，Lesson 和 WorkOrder 共同消费，不再各自维护副本。工单生成保留任务 ID、课次集合、实践学时、交付物、验收标准、工具/材料和安全/合规约束；冲突时失败并要求重新生成，不修改上游 Lesson。

Phase 2 包含：

- WorkOrder Content V1 schema、确定性映射和固定 10+90=100 评分；
- 可执行性、交付物、验收、有限跨专业污染和任务叙述反重复 QA；
- Practice Task → WorkOrder Cross-Artifact QA；
- 事务式安装器、只读依赖 doctor、Codex/Claude/Gemini/Copilot/Aider 适配器和项目本地运行时状态识别；
- 软件及非 IT 联动验收路径。

学生结果区保持空白，不生成教师答案。学生/教师固定评价 rubric 不参与跨工单反重复检查。不得为了降低重复率虚构任务、教材、文献或标准。模板 binary、模板版本和模板发布仍保持不变；Phase 3、成绩册联动和教师答案版不在本轮范围。
