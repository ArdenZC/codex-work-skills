# 教案生成器

## 简介

教案生成器用于批量生成项目化中文课程教案 DOCX。它内置了当前教案模板格式，默认按项目化教学设计课程单元和任务，可根据能力图谱、章节任务拆解 Excel、课程标准、教材目录或已有教案提取项目任务，也可以在资料不足时按课程名称和常见职业教育课程结构合理推断。

## 适用场景

- 按统一模板生成整门课程教案。
- 将旧版 `.doc` 或格式不统一的教案整理为 `.docx`。
- 根据能力图谱或章节任务拆解表拆分每次课教案。
- 为实训课生成少课时、成果导向、过程评价明确的项目化教案。
- 给教学评价设计补充自然真实的评分。

## 建议提供的资料

- 课程名称、专业、授课对象、总课时、每份教案课时。
- 能力图谱、章节任务拆解 Excel、课程标准、教材目录或旧教案。
- 如果不使用内置模板，可以另外提供 DOCX 模板。
- 输出文件夹、固定项目名称或任务名称等特殊要求。

## 默认处理

如果没有提供能力图谱或章节任务拆解，skill 会提醒需要哪些资料，但不会强制中断；它会按课程名称推断项目化结构，生成以“项目一、项目二……”为单元名称的教案，任务名称使用具体的学习或实训成果。

## 安装

将 `lesson-plan-docx-generator` 文件夹复制到本机 Codex skills 目录：

```powershell
Copy-Item -Recurse ".\教案生成器\lesson-plan-docx-generator" "$env:USERPROFILE\.codex\skills\lesson-plan-docx-generator"
```

也可以运行内置安装脚本：

```powershell
python ".\教案生成器\lesson-plan-docx-generator\scripts\install.py" --replace
```

macOS 或 Linux 可运行：

```bash
python3 "./教案生成器/lesson-plan-docx-generator/scripts/install.py" --replace
```

## 调用方式

在 Codex 中可以直接说：

```text
使用教案生成器，帮我根据这个能力图谱生成软件测试实训课程教案。
```

或显式调用：

```text
使用 $lesson-plan-docx-generator 生成项目化教案，课程名是数据库技术。
```
