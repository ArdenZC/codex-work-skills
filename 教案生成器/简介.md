# 教案生成器

## 简介

教案生成器用于批量生成项目化中文课程教案 DOCX。它内置了当前教案模板格式，默认按项目化教学设计课程单元和任务，可根据能力图谱、章节任务拆解 Excel、课程标准、教材目录或已有教案提取项目任务，也可以在资料不足时按课程名称和常见职业教育课程结构合理推断。

## 适用场景

- 按统一模板生成整门课程教案。
- 将旧版 `.doc` 或格式不统一的教案整理为 `.docx`。
- 根据能力图谱或章节任务拆解表拆分每次课教案。
- 为实训课生成少课时、成果导向、过程评价明确的项目化教案。
- 给教学评价设计补充自然真实的评分。

## 建议提供的资料

- 课程名称、专业、授课对象、总课时、每份教案课时。
- 能力图谱、章节任务拆解 Excel、课程标准、教材目录或旧教案。
- 如果不使用内置模板，可以另外提供 DOCX 模板。
- 输出文件夹、固定项目名称或任务名称等特殊要求。

模板已内置在 skill 包中，不需要另外提供 Word 模板：规范模板位于 `assets/templates/lesson-plan/v1.0.0/template.docx`，旧的 `assets/lesson-plan-template.docx` 仍作为兼容入口。`manifest.yaml` 记录模板坐标、可修改字段、保护边界和 SHA-256 指纹；输入契约见 `schemas/lesson-plan-input.schema.json`。

## 默认处理

如果没有提供能力图谱或章节任务拆解，skill 会提醒需要哪些资料，但不会强制中断；它会按课程名称推断项目化结构，生成以“项目一、项目二……”为单元名称的教案，任务名称使用具体的学习或实训成果。

## 安装

将 `lesson-plan-docx-generator` 文件夹复制到本机 Codex skills 目录：

```powershell
Copy-Item -Recurse ".\教案生成器\lesson-plan-docx-generator" "$env:USERPROFILE\.codex\skills\lesson-plan-docx-generator"
```

也可以运行内置安装脚本：

```powershell
python ".\教案生成器\lesson-plan-docx-generator\scripts\install.py" --replace
```

macOS 或 Linux 可运行：

```bash
python3 "./教案生成器/lesson-plan-docx-generator/scripts/install.py" --replace
```

## 调用方式

在 Codex 中可以直接说：

```text
使用教案生成器，帮我根据这个能力图谱生成软件测试实训课程教案。
```

或显式调用：

```text
使用 $lesson-plan-docx-generator 生成项目化教案，课程名是数据库技术。
```

## 多Agent兼容

本技能不把教案生成绑定到某一个模型或某一个 AI 工具。统一工作协议是：AI 负责理解课程资料并生成 tasks.json，内置 Python 脚本负责套用 DOCX 模板、生成教案和校验课时。包内同时提供 AGENTS.md、CLAUDE.md、GEMINI.md、通用提示词.md、Aider 约定，以及可安装到 Cursor、Cline、Continue、Windsurf 和 GitHub Copilot 的规则适配器。

其他工具请先读取通用提示词.md；需要把规则复制到另一个项目时，运行：
python lesson-plan-docx-generator/scripts/install_adapters.py --target-dir /path/to/project

生成流程为：输入资料 → 标准化数据 → schema 校验 → 模板校验 → 生成 → 输出校验 → `qa-report.json`。QA 报告会记录模板/生成器版本、实际模板路径、自定义模板标记、生成引擎和校验跳过项，不记录教案原始内容。脚本默认使用规范模板，也保留 `--template`、`--tasks-json`、`--output-dir`、`--backup-existing`；可选增加 `--manifest`、`--schema`、`--qa-report` 或显式跳过校验。跳过校验时仍生成报告，状态为 `skipped`。
