# 教案生成器

## 简介

教案生成器用于批量生成项目化中文课程教案 DOCX。它内置当前教案模板，默认按项目化教学设计课程单元和任务，可根据能力图谱、章节任务拆解 Excel、课程标准、教材目录或已有教案提取项目任务，也可以在资料不足时按课程名称和常见职业教育课程结构合理推断。

## 适用场景

- 按统一模板生成整门课程教案；
- 将旧版 `.doc` 或格式不统一的教案整理为 `.docx`；
- 根据能力图谱或章节任务拆解表拆分每次课教案；
- 为实训课生成少课时、成果导向、过程评价明确的项目化教案；
- 为教学评价设计补充自然真实的评分。

## 建议提供的资料

- 课程名称、专业、授课对象、总课时、每份教案课时；
- 能力图谱、章节任务拆解 Excel、课程标准、教材目录或旧教案；
- 如果不使用内置模板，可以另外提供 DOCX 模板；
- 输出文件夹、固定项目名称或任务名称等特殊要求。

如果没有提供能力图谱或章节任务拆解，Skill 会提醒需要哪些资料，但不会强制中断；它会按课程名称推断项目化结构，生成以“项目一、项目二……”为单元名称、以具体学习或实训成果为任务名称的教案。

## 模板与质量规则

模板已内置在 Skill 包中，不需要另外提供 Word 模板。默认规范模板为 `assets/templates/lesson-plan/v1.1.2/template.docx`，内置 70 个 Word 语义书签，书签名称符合 Word 40 字符限制，教学实施区使用短阶段代码，`start/end` 位于同一目标段落或物理单元格。

v1.1.2 在保留 v1.1.1 结构和语义书签的基础上，将固定评价标签泛化为“职业价值观”和“职业伦理”；两个课时的七个课中阶段严格合计 90 分钟，课前和课后安排不计入课中时长。版本—定位模式固定为 `1.0.x = legacy_coordinates`、`1.1.x = word_bookmark`，其他 `1.x` minor 不支持。v1.0 canonical、v1.1.0/v1.1.1 和旧 compatibility 路径仍可使用；自定义模板必须提供匹配 manifest 和实际 SHA-256 fingerprint。

生成流程为：读取现有资料并一次性核对关键缺口 → 课程级项目/任务规划 → Content Contract V2 JSON → Input/Content QA → 模板校验 → candidate DOCX → 输出保真校验 → 可选渲染 → 原子提交 → `qa-report.json`。V2 要求每课直接提供学情、目标、重难点策略、9 个实施阶段、13 项评价备注和差异化反思；Python 只格式化、映射和校验，不用 sparse input、旧套话、分数循环或静默截断。QA 报告记录模板/生成器版本、实际模板路径、自定义模板标记、生成引擎、Content QA、intra-lesson coherence 和校验跳过项；重复诊断只保留不超过 120 个字符的片段与稳定 SHA-256，不记录整段教案正文。显式跳过校验时仍生成报告，并将状态标记为 `skipped`。

## 平台支持

- Windows 和 macOS 是当前 CI 与交付验收平台；
- Windows、macOS 使用 Python 生成 DOCX，需要时可使用 Word 或 LibreOffice 做渲染检查。

## 安装

### 推荐：让 AI Agent 安装

将下面的提示词交给具备本地文件访问、Git 和终端执行能力的 Agent：

```text
请安装当前仓库中的教案生成器 Skill。

请先阅读：
- 仓库 README
- 仓库根目录的 AGENTS.md
- 教案生成器/简介.md
- 教案生成器/lesson-plan-docx-generator/AGENTS.md
- 教案生成器/lesson-plan-docx-generator/通用提示词.md
- 教案生成器/lesson-plan-docx-generator/SKILL.md

检查本机依赖后，将 lesson-plan-docx-generator 安装到当前 AI 工具对应的 Skill 目录，并验证安装结果。

如果当前工具是 Codex，优先使用 scripts/install.py。
不要修改源码、模板或 manifest。
```

纯网页聊天工具如果没有本机文件和命令权限，不能直接完成安装。

### Codex 手动安装

Windows PowerShell：

```powershell
python ".\教案生成器\lesson-plan-docx-generator\scripts\install.py"
```

macOS Terminal：

```bash
python3 "./教案生成器/lesson-plan-docx-generator/scripts/install.py"
```

默认安装到 `~/.codex/skills/lesson-plan-docx-generator/`。目标目录已存在时，默认不会覆盖；使用 `--replace` 才会先备份再替换，也可以使用 `--skills-dir <目录>` 指定 Codex skills 目录。`--dry-run` 只显示计划路径。

## 调用方式

在已安装的 Agent 中可以直接说：

```text
使用教案生成器，帮我根据这个能力图谱生成软件测试实训课程教案。
```

或显式调用：

```text
使用 $lesson-plan-docx-generator 生成项目化教案，课程名是数据库技术。
```

## 多 Agent 兼容

本 Skill 不绑定某一个模型或 AI 工具。Agent/模型负责理解课程资料并生成完整 `tasks.json`；内置脚本负责确定性地套用 DOCX 模板、生成教案和运行 QA，不会替模型创作正文。包内提供 `AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`通用提示词.md`、Aider 约定，以及可安装到 Cursor、Cline、Continue、Windsurf 和 GitHub Copilot 的规则适配器。

需要把规则复制到另一个项目时，运行：

```powershell
python "lesson-plan-docx-generator/scripts/install_adapters.py" --target-dir "<project>"
```

macOS 使用 `python3`。适配器会把最小可运行入口放在项目级 `.lesson-plan-docx-generator/` 命名空间中；共享 `AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、Copilot 和 Aider 规则使用本 Skill 的 marker 区块，与其他 Skill 共存。安装器先完成重叠/别名和 YAML 预检，再 staging、校验、提交；`--dry-run` 不创建目录、不移动文件，`--replace` 才替换普通适配器文件并保留碰撞备份，失败会回滚。
