# 教案生成器 2.2.3

教案生成器用于批量生成、整理和校验项目化中文课程教案 DOCX。

## 当前版本

| 项目 | 当前版本 |
| --- | --- |
| Lesson Skill | **2.2.3** |
| Lesson Content Contract | **2.2** |
| Practice Task Contract | **1.1** |
| 默认 Word 模板 | `lesson-plan v1.1.2` |
| 正式验收平台 | Windows、macOS |

Skill、内容合同和 Word 模板独立版本化；本次版本不修改模板 binary。

## 生产边界

- 先一次性确认课程基本盘，再生成完整课程 outline 和逐课内容；未确认的结构保持待确认，不自动推断。
- Lesson DOCX 只承载理论课时。每课按 `before=10` 分钟、`in_class=hours×45` 分钟、`after=15` 分钟记录，课外时间不计入课程学时；1 学时课也必须是 10/45/15。
- `course_materials.textbook`、lesson `resources` 和 `reference_pool` 分离。书籍作者/编者、书名、出版社必填，年份可选；没有可核验外部来源时允许空 reference pool，不写占位来源。
- 需要实践工单时，只从已确认课程基本盘单向生成 Practice Task Contract 1.1；Lesson 不反向保存实践任务 ID。
- Practice Task 与 WorkOrder 一一对应，每个 WorkOrder 固定 2 学时；关联模式保留完整 `source_task_snapshot`。
- 教学语义由 Agent 负责设计、审查和必要重写；Python 只做 schema、事实、小时、ID、精确重复、模板映射、输出和渲染等确定性门禁。
- 生产渲染失败、未执行或明确跳过都不能报告 Production PASS；调试 standalone 模式必须显式声明。

## 使用入口

```powershell
python scripts/install.py --help
python scripts/doctor.py --help
python scripts/generate_lesson_plans.py --help
```

历史 Content 2.1/2.0 只走显式 `--legacy` 兼容路径；新会话默认使用 Content 2.2 与 Practice Task Contract 1.1。
