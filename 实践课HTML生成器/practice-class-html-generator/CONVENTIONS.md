# Aider / project conventions

- Agent 创作合同，Python renderer 生成 HTML。
- 保持课程泛化；foundation-kit 随课程动态变化。
- 不复制旧 WorkOrder Hardening；只运行必要的合同、关联、HTML 和浏览器 QA。
- New Practice generation inherits strict Courseware Source Truth and time evidence; migration-trust is reserved for legacy regression.
- Core task time is an estimate supported by optional `time_breakdown`; the reviewer catches implausible inflation without imposing a fixed task count or stopwatch.
- Student packages omit canonical facts, replacement metadata, and time-planning fields; teacher guidance may show human-readable time evidence.
