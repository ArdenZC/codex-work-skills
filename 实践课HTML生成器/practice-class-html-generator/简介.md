# 实践课 HTML 生成器 Skill

这是一个轻量的实践课内容 Skill。它不生成 DOCX 工单，也不复用旧 WorkOrder 的 Phase、Hardening、事务、模板指纹或复杂防御体系；它只关心实践内容是否能做、是否接上已讲理论，以及 HTML 是否真的能打开和互动。

Agent 负责理解课程资料并创作 `Practice Class Content Contract 1.1`；renderer 根据合同生成四个学生模块、两个教师模块、学生/教师分离包、JSON 合同、QA 报告和可选 starter，模块内容在同一 HTML 内以 pane 切换。实践课默认面向高职/大专课堂，核心路径是：看懂理论 → 预测/操作 → 补核心 → 完成结果 → 能解释。

首选调用方式是同时传入 Practice Contract 和 Courseware Contract 1.1：

```powershell
python scripts/render_practice.py `
  --practice-json examples/data-structures.practice.json `
  --courseware-json ..\..\HTML课件生成器\courseware-html-generator\examples\data-structures.example.json `
  --output-dir .\out\data-structures --replace --json
```
