# Excel 数据处理基础：公式、筛选与结果呈现

## 课程背景

本节面向高职或大专学生，学生能打开 Excel 工作簿、录入数据并进行简单格式设置，
但公式和数据处理基础一般。上课使用 Windows 和 Microsoft Excel 桌面版。教师提供
一份小型销售记录 CSV 作为课堂数据。理论课按 120 分钟准备，随后安排 120 分钟机房
实践。

## 本节范围

本节材料涉及以下 Excel 知识：

- 工作表中的字段、记录、单元格地址和数据类型；
- 相对引用、绝对引用，以及复制公式时引用如何变化；
- `IF` 根据条件返回不同结果；
- `COUNTIF` 按条件统计记录数量；
- 对记录进行筛选，并理解筛选后“隐藏”与“删除”的差异；
- 用简单图表表达按类别或按月份的汇总结果，并根据问题选择合适图表；
- 对 CSV 导入后的字段类型、空白值和日期显示进行检查。

本节只涉及基础工作表操作和简单汇总，不展开 VBA、宏、复杂数据模型、外部数据库
连接或复杂 Power Query。若软件版本提供导入/刷新入口，可以把 CSV 的重新导入和
字段检查作为工具说明，但不要把超出上述范围的功能当成本节必备知识。

## 概念说明

一个工作表可以看作由字段列和记录行组成。公式写在单元格中，引用的是单元格位置
或区域；复制公式时，相对引用会跟着位置移动，绝对引用用 `$` 固定列、行或两者。
判断一列数据是否满足条件时，`IF` 适合产生分类或提示，`COUNTIF` 适合回答“有多少
条记录满足条件”。函数结果要结合字段类型和实际数据检查，不能只看公式是否被接受。

筛选改变的是当前显示的记录集合；筛选后仍要注意状态栏、复制范围和清除筛选，避免
把“看不见”误解成“已经删除”。图表应服务于要回答的问题：随时间看趋势、比较类别
差异和查看构成时，关注的视觉关系不同。

## 公式素材

下面的表达式用于课堂解释，具体放在哪一列要结合导入后的工作表字段来判断：

```text
=IF(E2>=1000,"重点","普通")
=COUNTIF(F:F,"重点")
=IF(C2="","缺少日期",C2)
```

如果某个阈值写在单独的参数单元格中，复制公式到其他行时，应考虑是否需要固定该
参数单元格。例如参数在 `H1` 时，引用方式可能需要写成 `$H$1`；固定与否取决于
公式的意图，而不是一个必须背诵的符号规则。

## 操作观察素材

导入 CSV 后先看列标题、前几条记录和明显的空白/异常值，再决定怎样计算。使用筛选
时记录筛选条件，清除后确认记录是否仍在。制作图表前先明确要比较的字段和聚合方式，
图表完成后检查标题、类别标签和数值是否与工作表结果一致。

## 结果讨论

课堂讨论可以围绕这些现象展开：复制公式后结果为什么改变；阈值放在参数单元格时
为什么有时要固定引用；一条空白记录会怎样影响判断；筛选后的可见记录与原始记录
数量有什么关系；一个图表是否真的回答了当前业务问题。学生应能把公式、显示结果和
数据含义联系起来，而不只是记住函数名称。
