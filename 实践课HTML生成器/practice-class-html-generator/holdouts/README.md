# Architecture Diversity Fixtures

`source-packs/`、`practice-contracts/` 和 `build_holdouts.py` 是既有的
ARCHITECTURE DIVERSITY FIXTURES。它们预先提供了 Courseware/Practice 合同，
用于回归：

- Contract 兼容；
- renderer 与 validator；
- capability/scaffold 与 visualization adapter；
- Student/Teacher package isolation。

它们不是 Blind Teaching Generalization Test，不能用其中的历史分数宣称
Skill 已经从陌生资料自主完成教学设计。历史 `93.8` 只能称为
architecture compliance score 或 structured contract diversity score。

真正的盲测输入位于 `blind/`。`blind/` 只包含冻结前的原始资料、课程背景和
必要数据；任务、互动、学习中心、脚手架和参考成果必须由独立 Agent 首轮决定。
