# 实践课 HTML 生成器 1.0.0

实践课 HTML 生成器把已经讲授的理论课内容转成可在机房或实训课堂直接使用的实践材料：详细任务书、互动学习中心、理论关联学习资料、课程基础补给站和教师课堂指导。它面向数据结构、软件建模、数据库、人工智能、工具操作等不同课程，不把某一种语言或工具写死在产品里。

首选输入是 `Courseware Content Contract 1.0`。Agent 先根据理论课件创作 `Practice Class Content Contract 1.0`，实践知识点和任务通过 `source_slide_ids` 与理论页建立可检查关联；Python renderer 只负责稳定生成 HTML、starter 文件和精简 QA，不代替 Agent 创作教学内容。

## 输出

- `student-task.html`：学生可按步骤完成的 core / optional / challenge 任务书；
- `learning-center.html`：与具体任务和知识点绑定的预测、匹配、诊断或步骤互动；
- `study-guide.html`：只围绕本次理论范围整理的学习资料；
- `foundation-kit.html`：按课程动态生成的语法、工具或建模基础补给站；
- `teacher-guide.html`：教师备课与课堂指导；
- `practice-content.json`、`qa-report.json`，以及需要时的 `starter/`。

## 泛化示例

仓库内提供三套内容差异明显的 fixture：数据结构算法/代码脚手架、软件建模/UML 建模工具、数据库 SQL/ER/工具操作。示例都可以从对应的 Courseware Contract 读取理论页并验证 `source_slide_ids`。

完整合同、命令和 QA 见 [practice-class-html-generator/README.md](practice-class-html-generator/README.md)。
