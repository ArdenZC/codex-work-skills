# HTML 课件生成器 v1.2.1

HTML 课件生成器把课程教材、PPT、讲义、教案或其他课程资料整理为两份完全离线的单文件 HTML：学生课堂展示版和教师逐页备课版。

它不是让模型每次手写一套 HTML/CSS/JavaScript。Agent 负责理解资料、规划页面、创作学生内容和自然中文逐字稿，并提交 `Courseware Content Contract 1.1` JSON；Skill 内置的确定性 renderer 负责统一视觉系统、布局、导航、交互控件、SVG/代码/表格/练习/stepper 渲染和 QA。

## 输出

- `student.html`：16:9 教室投影优先的明亮莫兰迪学院风展示版；不显示制作信息、教师备注或建议时长。
- `teacher.html`：与学生版逐页一一对应，左侧保留同一课堂页，右侧提供可以直接照着讲的连续中文逐字稿和最多三个辅助提示框。
- `qa-report.json`：内容合同、离线单文件、禁用词、逐页对应关系和 HTML 约束的确定性报告。

两份 HTML 均不依赖服务器、CDN、网络图片、外部字体或 npm runtime，Chrome / Edge 可直接双击打开。学生版支持非交互区域点击翻页、滚轮翻页、键盘翻页、练习答案、stepper 和投影增强。

## 调用

```text
使用 HTML课件生成器，根据我上传的教材第6章内容生成课堂课件。
默认面向大专学生，准备约120分钟的内部内容储备，但不要在学生课件显示任何时长或制作信息。
同时生成学生展示版和教师备课版。
```

也可以自然调用：

```text
把这一章做成课堂课件，还是按我之前的标准。
```

资料不足时，Agent 可以使用明确标注的通用教学结构，但不得伪造用户未提供的教材页码、文献、数据或事实来源。默认授课对象为高职/大专学生，理论深度不自动扩展到本科考研级别。

## 安装

Windows：

```powershell
python ".\HTML课件生成器\courseware-html-generator\scripts\install.py"
```

macOS / Linux：

```bash
python3 "./HTML课件生成器/courseware-html-generator/scripts/install.py"
```

目标已存在时默认不覆盖；使用 `--replace` 才替换，`--dry-run` 只显示计划，`--skills-dir` 可指定 Codex skills 根目录。安装器不会自动安装 Python 或 npm 依赖。

完整的 Content Contract、命令和 QA 规则见 [courseware-html-generator/README.md](courseware-html-generator/README.md)。
