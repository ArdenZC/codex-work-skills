# HTML 课件生成器 1.0.0

这是一个把 Agent 创作的 `Courseware Content Contract 1.0` 渲染为两份离线单文件 HTML 的 Skill：学生课堂展示版和教师逐页备课版。

先阅读 `通用提示词.md`、`SKILL.md` 和 `AGENTS.md`。Agent 负责理解教材、PPT、讲义或教案并创作页面内容与自然中文逐字稿；Python renderer 负责稳定的 CSS/JavaScript、SVG/代码/表格/练习/stepper、点击/滚轮/键盘翻页、离线输出和 QA。不要直接手写最终 HTML，也不要在内容 JSON 中嵌入任意 JavaScript。

输出必须是 Chrome/Edge 可用 `file://` 直接打开的 `student.html`、`teacher.html` 和 `qa-report.json`，不依赖服务器、CDN、外部字体、网络图片或 npm runtime。
