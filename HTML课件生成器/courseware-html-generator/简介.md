# HTML 课件生成器 1.2.1

这是一个先从 Raw Source 建立 Teaching Blueprint、再把 Agent 创作的 `Courseware Content Contract 1.1` 渲染为两份离线单文件 HTML 的 Skill：学生课堂展示版和教师逐页备课版。旧 1.0 输入仅通过迁移兼容。

先阅读 `通用提示词.md`、`SKILL.md` 和 `AGENTS.md`。Agent 负责理解教材、PPT、讲义或教案并创作蓝图、页面内容与自然中文逐字稿；Python 依次执行结构校验、教学审查、最多两轮安全合同修复、重新校验、稳定 renderer、离线输出和 QA。不要直接手写最终 HTML，也不要在内容 JSON 中嵌入任意 JavaScript。

输出必须是 Chrome/Edge 可用 `file://` 直接打开的 `student.html`、`teacher.html` 和 `qa-report.json`，不依赖服务器、CDN、外部字体、网络图片或 npm runtime。
