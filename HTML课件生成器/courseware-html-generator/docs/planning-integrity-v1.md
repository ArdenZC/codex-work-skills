# Planning / Formula Integrity 1.0 (Skill 1.2.1)

Content Contract remains 1.1 with additive `integrity_version:"1.0"`. Keep Source Truth, Time Evidence, learning units, canonical facts, not-yet-taught and existing visual/runtime gates unchanged.

Plan each page from learning-unit difficulty, visual complexity, explanation need, activity type and observation/editing burden. Record `planning_rationale` on each slide and corresponding public generation-decision.json rationale. Decide page/time distribution after this analysis; do not divide the prepared duration by a fixed page count. Equal numbers alone are not an error. Do not randomize counts/times to simulate diversity.

The script hard floor (80 meaningful chars per lecture minute) is the lowest acceptable boundary. Default authoring target is 120–160 chars per lecture minute: teachers should be able to read the script naturally. Explain actual diagrams/tables/code, use concrete examples, anticipate errors, ask and respond, then transition. Never fill length by copying or padding. Courseware Gold batch review excludes cover/index/very-short summary/extension pages and records core-page script rates, minimum/median/maximum, below-normal ratio, near-floor ratio, repeated n-grams, repeated paragraphs and visual-explanation coverage. Repetition and n-gram checks remain active. Missing normal-target capacity is DEGRADED and loses pedagogy credit; the Gold closure gate passes only when the below-normal ratio is below 25% and no hard-floor or visual-coverage failure is present.

Courseware planning defaults to `session_delivery_mode: "theory-led"`. Each non-zero activity may declare `activity_role` as teacher-led demonstration, guided whole-class reasoning, short student check or student independent practice. When a separate Practice asset exists, the boundary review uses the relative minutes of those roles as a heuristic; it does not enforce a fixed ratio.

Each slide may supply `script_coverage` mapping labels (visual_explanation, example, question_response, transition, misconception, etc.) to exact excerpts from its final speaker_script. The verifier checks excerpts exist; human review checks whether they truly explain this page. At least three kinds of evidence avoid a coverage warning in strict review. This is not a quota for paragraphs. Batch review via `planning_integrity.review_batch(contents)` compares count, lecture/activity distributions, segment patterns, activity types, layout sequence and script density; correlated repeated structures and floor-hugging scripts produce TEMPLATE_OVERFIT_WARNING. Record warning honestly or explicit human review status, never silently change it to PASS.

All displayed spreadsheet IF/COUNTIF/SUM/SUMIF/AVERAGE formulas need root `formula_facts:[...]`. Fact fields: id, formula, example_scope. Abstract syntax examples set example_scope=abstract and show “语法示例” to students. A formula claiming applicability to current data sets example_scope=current-dataset, source_id (CSV path under --source-root), semantic_intent, bindings with input_field or input_fields (exact source headers), operation_location, optional expected_result. The shared formula_truth.py derives column index/letter/name/sample/type, checks actual formula columns against intended fields, and evaluates supported expressions. Do not claim unsupported syntax is verified. Current-dataset examples must clearly say that they apply to the current workbook. Theory examples may include abstract formulas without pretending they fit current data.

Inherit delivery_environment in course_context from supplied course facts. Keep public decision evidence teacher/QA only. Preserve the two single-file offline HTML surfaces and existing navigation behavior. Automatic pedagogy score is 30 only for PASS, lower for DEGRADED; automatic acceptance does not replace Human PENDING /40.
